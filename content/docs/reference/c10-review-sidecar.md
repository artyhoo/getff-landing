## What it is

"> **Authoritative for:** `review-sidecar` sub-agent prompt — adversarial diff review as external reviewer; reporting-only." (`agents/review-sidecar.md:9`). The seat is memory-free by construction: "You are reviewing this diff as if you were an external reviewer who has **NEVER** seen this code before. …" (`agents/review-sidecar.md:19`). It is "the formalization of the **two-AI review pattern**: one model writes, a different model reviews without context." (`agents/review-sidecar.md:23`). The install story is the collision-resolution case: "#   - review-sidecar — still collides with AIF's. copy_safe DEFAULT (no --force) intentionally" skips it when AIF's own is present (`setup.d/20-agents.sh:15-17`), while "#     agents/review-sidecar.md remains the portable SSOT (@dual-pair anchor: review-sidecar)." (`setup.d/20-agents.sh:22`). A plugin twin at `plugin/agents/review-sidecar.md` is a generated byte-identical copy for the plugin marketplace channel (verified line-for-line at authoring time).

## How it works

- Anti-tautology content still reaches AIF's `aif-review` pipeline without overwriting AIF's agent — via the skill-context override: "also delivered into AI Factory's pipeline via the skill-context override at" `packages/core/templates/shared/skill-context/aif-review/SKILL.md` (`agents/review-sidecar.md:13-17`), and on the setup side "# instead of shipping colliding agents: aif-review gets our anti-tautology test-review content;" (`setup.d/20-agents.sh:58`).
- "## What to look for" (line 29) — eight categories: "### 1. Tautological tests" (line 31), mock-only tests (line 63), missing edge cases (line 76), test name ≠ behavior (line 87), test independence (line 103), React-specific anti-patterns (line 113), "### 7. Next.js-specific anti-patterns" (line 125), React testing anti-patterns (line 134).
- The tautology heuristic: "**Heuristic:** for each `expect(...)` in the diff, ask "if I removed this, what bug could now ship?" If the answer is "none" — it's tautological." (`agents/review-sidecar.md:61`).
- Severity: "- **BLOCKER** — security/correctness/data integrity (allows silent breakage; e.g., tautological test on critical path)." (line 162); round-triggering findings need a `Failure-scenario:` line per the severity contract (line 158).
- Final verdict: "## Two-AI Review Summary" with "BLOCK MERGE — fix BLOCKER before proceeding." or "APPROVE — review passed." (lines 170-191).
