**Experimental.** The factory's pieces do not all have to be present for work to
continue — but when a capability is absent, something specific degrades, and the
degradation is named rather than papered over. A degradation row answers one question:
with X missing, what still works, and what gets worse. The matrix below is copied
verbatim — row text unchanged — from the one file that owns it; this page is a pointer,
never a second source. Read the rows as evidenced claims, not probe-verified facts:
each names the probe class that will validate it later, and that validation has not run
yet.

Columns: `| Capability absent | Tier-system degradation | Current evidence source | C3-validation status |`
